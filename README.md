# weather-tracker

Track weather observations and forecasts.

## Requirements

- Python 3.13
- [Poetry](https://python-poetry.org/) 2.2.1

## Setup

```bash
poetry sync
```

Poetry creates `.venv` in this directory and uses Python 3.13.
